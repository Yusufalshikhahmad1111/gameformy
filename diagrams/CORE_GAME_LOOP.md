# Core Game Loop

```text
LOBBY
  ↓
PARTY / TEAM
  ↓
MAP + MODE
  ↓
SPAWN
  ↓
SECURE HOME PROVINCE
  ↓
CREATE / MOVE ARMY
  ↓
ATTACK CASTLE
  ↓
4-GATE CONTEST
  ↓
10s UNCONTESTED CAPTURE
  ↓
PROVINCE CHANGES COLOR
  ↓
CASTLE GENERATES SUPPLIES
  ↓
BIGGER / BETTER ARMY
  ↓
FORMATIONS + BATTLES
  ↓
BREAKTHROUGH / COUNTERATTACK
  ↓
VICTORY
  ↓
REWARDS / REMATCH / PARTY
```
