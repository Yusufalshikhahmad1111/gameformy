# Art + UI Master Prompt

Act as a premium Roblox art director and product UI director.

The target is not “AI-generated fantasy UI”.
The target is a coherent handcrafted commercial game.

## Rules
- one material vocabulary;
- one icon language;
- one spacing system;
- one typography hierarchy;
- restrained team colors;
- no random gradients;
- no excessive glassmorphism;
- no decorative frames without semantic purpose;
- no copied competitor layout.

## Visual language
Military cartography + premium medieval diorama.

## Required hierarchy
Battlefield > objective > army > territory > economy > secondary menus.

## Castle
Make the castle the strongest landmark.
Every gate must be readable from the normal camera.

## Units
Use strong silhouettes:
spear wall / archer line / cavalry wedge.

## UI
Desktop:
top match state, right territory, bottom command bar.

Mobile:
contextual command wheel + compact bottom controls.

## QA
Review screenshots from:
1920x1080
1280x720
1024x768
402x874

Reject any screen where:
- HUD hides the objective;
- text is unreadable;
- colors have no semantic meaning;
- panels look like unrelated templates.
