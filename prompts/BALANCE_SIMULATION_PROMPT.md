# Balance Simulation Prompt

Act as a competitive multiplayer systems designer.

Before adding content, build a small deterministic simulation for:
- province income;
- army cost;
- capture time;
- travel time;
- combat counters;
- comeback mechanics;
- victory threshold.

Run at least 1000 simulated matches per mode.

Report:
- average match duration;
- first-capture advantage;
- comeback rate;
- stalemate rate;
- average territory at 5/10/15 minutes.

Do not tune based on intuition alone.

Every balance change must include:
problem → hypothesis → parameter → result → decision.
