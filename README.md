# GAMEFORMY — Kingdoms Conquest

Roblox real-time territorial strategy game production bible v2.0.

The complete design package is preserved in `releases/gameformy_kingdoms_conquest_v2.zip`.

Core fantasy: command a living kingdom, capture provinces through castles, build an army from conquered income, and personally direct formations in real-time battles.

Quality bar: original art, premium handcrafted UI, server-authoritative multiplayer, mobile-first controls, short readable matches, measurable systems.
