## Pacing targets
| Event | Target |
|---|---:|
| Spawn to first meaningful order | < 20s |
| Spawn to first objective | 45–90s |
| First capture attempt | 2–3 min |
| First major battle | 3–6 min |
| Strategic turning point | 6–10 min |
| Typical match end | 10–16 min |
| Hard cap | 20 min |

## Map density
Castles should be visually and physically close enough that travel is never the main gameplay.

Rule of thumb:
**the player should usually see the next strategic objective before they reach the current one.**

Use terrain to create meaningful routes rather than distance.

## 2-team layout
Mirror or near-mirror starting areas.
Central contested province.
Two side routes.
One high-value strategic province.

## 3-team layout
Triangular start.
Central neutral objective.
Three side provinces.
No formal alliances in MVP.

## 4-team layout
Four corners or four radial starts.
More neutral territory.
Shorter travel.
More defensive value on home provinces.

## Match phases
### Phase 1 — Expansion
Players secure income.

### Phase 2 — Contact
First castles become contested.

### Phase 3 — War
Armies collide and strategic routes matter.

### Phase 4 — Breakthrough
A team takes a key province and must decide whether to consolidate or attack.

### Phase 5 — Endgame
Victory condition becomes obvious. The losing team gets a viable final push.

## Anti-stall
At 12+ minutes:
- increase value of contested objectives;
- reduce low-value travel;
- surface victory progress clearly.

At 18 minutes:
- trigger an endgame rule rather than allowing indefinite cleanup.
