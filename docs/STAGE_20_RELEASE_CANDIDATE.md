# Stage 20 — Release Candidate & Live Operations
## Objective

Package the first real production candidate.

## Release checklist

Gameplay:
- match lifecycle stable;
- army combat stable;
- castle capture stable;
- bots stable;
- economy stable.

UX:
- mobile-first;
- Arabic/English;
- onboarding;
- results;
- rematch;
- reconnect.

Art:
- hero castles;
- final launch map identity;
- final army silhouettes;
- lighting;
- effects.

Engineering:
- persistence;
- rate limits;
- error recovery;
- telemetry;
- performance;
- rollback plan.

Safety/product:
- final review of world naming and real-world sensitivity;
- age/audience fit;
- moderation implications;
- platform compliance review.

## Definition of Done

A new player can:
Launch → understand the lobby → enter a match → recruit → command → capture → fight → win/lose → receive results → rematch.

The entire loop is verified in Roblox Studio and documented.
