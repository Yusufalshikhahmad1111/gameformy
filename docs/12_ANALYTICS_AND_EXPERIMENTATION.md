# 12 — Analytics and Experimentation

## Events
Track:
- lobby_join
- match_start
- first_command
- first_capture_attempt
- first_capture
- first_battle
- castle_lost
- castle_recaptured
- match_end
- rematch
- party_created
- party_joined
- tutorial_step_complete

## Match metrics
- duration;
- team size;
- province control timeline;
- income per minute;
- army size;
- capture attempts;
- contested captures;
- comeback events.

## Funnel
Install/join
→ lobby
→ match
→ first command
→ first capture
→ match completion
→ second match
→ party/repeat session.

## Experiments
Only change one meaningful variable at a time:
- objective distance;
- capture duration;
- income;
- onboarding copy;
- UI placement.

## North-star candidates
Early:
**second-match rate**.

Later:
**weekly retained players who complete multiple matches**.

Do not optimize raw session length if it is produced by boring travel.
