# Kingdoms Conquest — Comprehensive World/Runtime Audit
Date: 2026-11-08

## Completed

- Removed the custom tactical camera (Stage3Camera.client.lua). Roblox's default camera controller is now authoritative.
- Mounted the Lobby as an editable Workspace model so it exists in Edit mode.
- Mounted four editable world regions in Workspace: Map_Syria, Map_SaudiArabia, Map_Palestine, Map_Europe.
- Separated the four regions into a large world grid: Syria (-1100,-1100), Saudi Arabia (1100,-1100), Palestine (-1100,1100), Europe (1100,1100).
- Added editable roads, rivers, terrain, regional props, city castles, four gate openings, banners and spawn/visitor pads to each map.
- Added E-based travel from Lobby to every region.
- Added E-based return to Lobby and travel pads between regions.
- Added runtime labels and interaction metadata to static castles/gates.
- Runtime gameplay still owns authoritative state/capture/combat, but its generated world geometry is now invisible gameplay proxies so it does not visually duplicate the static maps.
- Stage 9 runtime art no longer creates a second visual layer over a static map.
- Territory overlays were flattened and made non-collidable so they cannot float the player above castle walls.
- Reworked army visuals from cylinders into small stylized soldier/cavalry bot formations with bodies, heads, legs, shields, spears, bows, horses, riders and banners.
- Hid the tactical minimap outside active matches.
- Repositioned desktop HUD panels to avoid minimap/recruit overlap.
- On touch devices, desktop command/recruit panels are hidden and replaced by one compact command/recruit panel.
- Static castle/gate attributes are added at runtime so world clicking and capture UI can identify them.

## Architecture

Edit mode: Lobby + 4 editable map prefabs are visible in Workspace.

Play: Lobby remains the physical starting area -> E opens the Kingdoms lobby UI -> map portals allow region travel -> selected match activates the authoritative runtime proxy -> visible map remains the static prefab -> armies/combat/capture remain server authoritative.
