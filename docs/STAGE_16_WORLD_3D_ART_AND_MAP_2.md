# Stage 16 — World 2.0, 3D Art & Map Production
## Objective

This is the major visual leap.

The battlefield must stop looking like a collection of parts and start looking like a designed strategy diorama.

## Art hierarchy

1. Capital castle
2. Major castle
3. Regional castle
4. Army
5. Roads / rivers / terrain
6. Territory
7. Props

## Castle production

Create three final kits:
- Capital;
- Major;
- Regional.

Each kit needs:
- clear gate openings;
- walls;
- towers;
- courtyard;
- banner;
- hero silhouette;
- readable approach;
- low-detail distant variant.

## World production

Each map gets:
- terrain family;
- road language;
- river/crossing logic;
- vegetation family;
- architecture family;
- landmark family.

## Hero assets

Before mass production:
- build one excellent capital;
- build one excellent major city;
- build one excellent regional castle.

These become the visual bar for every other asset.

## Army art

Replace generic blocky soldiers with:
- readable silhouettes;
- role-specific equipment;
- banners;
- formation poses;
- marching state;
- combat state;
- retreat state.

## Terrain

Use:
- plains;
- hills;
- dry terrain;
- rocky terrain;
- urban surfaces;
- riverbanks.

Terrain must influence gameplay, not only appearance.

## Performance

Use:
- modular assets;
- shared meshes;
- distance variants;
- low-cost props;
- streaming;
- controlled collision;
- minimal runtime decoration.

## Definition of Done

Every launch map:
- looks intentional from far away;
- remains readable at battle distance;
- has no graybox placeholder castle as the primary landmark;
- has roads that match gameplay routes;
- keeps armies visible against terrain.
